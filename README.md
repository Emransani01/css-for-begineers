# HTML & CSS for Beginners

This repository contains my beginner-level practice code for learning HTML and CSS fundamentals.

The project includes simple examples and exercises focused on understanding HTML structure and basic CSS styling.

## 📚 Topics Covered

### HTML

- Basic HTML document structure
- Headings
- Paragraphs
- Strong and emphasis elements
- Ordered lists
- Unordered lists
- Links
- Semantic HTML elements
- Navigation
- Header
- Main
- Section
- Footer

### CSS

- Internal CSS
- Inline CSS
- CSS selectors
- Class selectors
- Text colors
- Font sizes
- Font family
- Padding
- Basic element styling
